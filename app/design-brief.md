# webmasters.bg redesign - design brief

**Design read:** Bulgarian SMB owners (interior studios, clinics, photographers, e-commerce) evaluating a web agency; register = calm, premium, confident, like a high-end template storefront (reference: Grigoletto Figma pack sales page).

**Concept spine:** "The site assembles itself." A website is built live in front of the visitor: wireframe light becomes structure, structure becomes glass, glass becomes a finished product. The page then sells like a clean product page: what you get, proof, who it is for, how it works, the offer, FAQ, contact.

**Delivery tier:** cinema (scroll-scrubbed film hero + scroll chapters, transform-only micro motion, magnetic CTA).

**Locked palette (user's explicit brand colors: "dark navy environment, electric green accent"):**
- ground #0A1024, surface #0F1733, raised #141E40
- ink #EEF1F8, muted #9AA3BD, hairline rgba(238,241,248,.12)
- accent #2CFF7A (single accent: CTAs, active states, rails)
Defense: navy + green is the user's requested brand direction; overrides the neon-on-dark ban by explicit request.

**Locked type:** Geist (display + body, Cyrillic) + Geist Mono (captions). No serif.

**Corner rule:** media and panels 14px (28px for large panels); interactive controls are full pills.

Animation mode: animated-website

**Journey shape:** single-shot (one continuous 15s MiniMax H3 film, split at exact frame boundaries into 4 consecutive segments so each chapter owns a stretch of the same take; seams are pixel-identical).

**Journey:**
1. Start (wireframe lines draw an empty browser frame): "Сайтове, които продават." + primary CTA.
2. Структура (layout grid drawn in light): "Първо структура."
3. Разработка (blocks extrude into glass, exploded orbit): "Код без шаблони."
4. Растеж (layers lock into one glowing slab): "Пускане и растеж."
The film literally builds a website while the chapters describe the same process.

**World grammar:** seamless deep navy void, faint haze, electric green wireframe light, frosted glass layers, green rim light, slow push-in then gentle 30 degree orbit, no text in frame.

**Mobile framing:** subject center-safe; 720p mobile encode; copy docks to bottom with scrim.

**Delivery budget:** desktop <= 32 MiB, mobile <= 16 MiB.

**Section plan (families):**
1. Journey (scroll-scrub film)
2. Services: sticky heading + divided list with generated icons
3. Projects: horizontal pan gallery of large generated concept visuals
4. Audience: big-type hover list over generated plate
5. Process: vertical timeline with scroll-filled rail
6. Offer: framed panel + checklist + block CTA
7. FAQ: accordion
8. Contact: split copy + real form (D1 leads table)
Footer with oversized drifting wordmark.

**Asset plan (Higgsfield):** storyboard, film, 4 project concept visuals, plate, 6-glyph icon sheet (sliced), W monogram + head kit, cover + OG.

**CTA inventory:** NavCta (outline pill, floods green), MagnetCta (hero, filled pill + arrow disc, magnetic), DrawLink (drawing underline), OfferCta (block bar, travelling arrow), SubmitCta (outlined pill, green sweep).
